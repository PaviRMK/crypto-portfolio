# CryptoTrack

## Project Description

CryptoTrack is a full-stack web application that helps users manage and track their cryptocurrency investments. The platform allows users to monitor their portfolio value, track performance, analyze profit and loss, and receive investment insights.

This project was developed to improve cryptocurrency portfolio management and provide users with better investment decisions.

## Features

- Add and manage crypto holdings
- Track portfolio performance
- Profit and Loss calculation
- Risk alerts and notifications
- Scam token detection
- Tax estimation support
- User-friendly dashboard

## Tech Stack

### Frontend
- React.js
- JavaScript
- CSS

### Backend
- Spring Boot
- Java
